# Preschool scene review — 2026-11-10

Private adult review material for children around age five. The current batch
contains **eight continuous conversations**, 15–26 seconds each, with 2–4
speaking characters and 4–8 actual dialogue turns per scene. English/Chinese
subtitles, named roles, and source notes accompany every MP4. Suggested age fit,
caption wording, and role assignments remain subject to adult listening review.

## Selection standard

The owner identified **No, this is Patrick!**, **Chocolate?!**, and **Ogres are
like onions** as the right format and length. Use a compact scene with a setup,
responses, and payoff. Multiple sentences from one narrator, isolated vocabulary,
and catchphrases do not meet the requirement. Count dialogue turns when the
speaking character changes, rather than splitting one speaker’s sentences into
extra lines. Each selected scene is one uninterrupted source range, with no
concatenation of unrelated moments.

These cuts range slightly beyond the approximately 11–16 second reference
clips where necessary to retain the complete exchange. The longest scene is approximately
25 seconds. The eight conversations total approximately 173 seconds.

## Preparation and verification

`content/preschool-review-scenes.json` contains the source-relative cut/line
times, named roles, English text, Chinese hints, and opaque clip/role/line IDs.
Source video IDs retain the external provider’s format. VTT times are relative
to the prepared clip; recipe and index times are relative to the source upload.

Keep the five source originals named `<YouTube ID>.mp4` under
`content/local-dubbing/review/younger-age-5/sources/`. FFmpeg and FFprobe are
required. No audio was generated.

```sh
node scripts/prepare-review-clips.mjs younger-age-5
# Regenerate one scene:
node scripts/prepare-review-clips.mjs younger-age-5 05-peppa-found-glasses
# Check the scene contract, media duration/decoding, and bilingual captions:
node scripts/prepare-review-clips.mjs younger-age-5 --check
```

The preparation script rejects one-speaker excerpts, narrator-led substitutes,
clips under ten seconds, and scenes with fewer than three actual character
turns. The current selections exceed those minimums: each has 4–8 turns.
All eight outputs passed full FFmpeg decoding, audio/video stream checks,
duration checks, and caption-presence checks. A second speech-recognition pass
on the actual cuts supports the draft wording; visual frame sheets were also
inspected. This does not replace adult listening and suitability review.
Screenshots and preview sheets are saved under
`~/Pictures/Screenshots/Codex/parrot-english/`.

`node scripts/prepare-test-packs.mjs` prepares the 32-scene application catalogue,
pack manifests, hashed media filenames, posters, and original-audio waveforms.
It uses the saved word alignments and preserves the three benchmark media files.
Upload media from the generated ignored `release-metadata/media.json` manifest
to the existing OSS bucket before merging metadata changes. This release uses
58 new objects (29 videos and 29 posters); the existing benchmark objects are
preserved. Only GitHub `main`
triggers the ESA code deployment. The shelf defaults to 24 older scenes; the
“5岁左右” folder contains the eight younger conversations. The URL keeps the
selected folder through scene navigation and reload.

This uses the existing deployment and access settings. It does not add or verify
a VPN allowlist. Source and unconfirmed-rights notices remain visible.

The [2026-11-10 speaker and cut audit](lesson-audit.md) corrects speaker labels,
keeps minor parts out of the practice picker, and retains complete source endings.
